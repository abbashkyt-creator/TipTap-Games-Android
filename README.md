## Install on Android

1. Open the link above in Chrome on the phone.
2. When Chrome warns that the file type can harm the device, tap **Download anyway**.
3. Open **Downloads**, tap `TipTapGames.apk`.
4. Android asks to allow installs from this source - allow it for Chrome (or the file manager).
5. Tap **Install**, then **Open**.

If Play Protect shows "unsafe app blocked", tap **More details -> Install anyway**. The APK is signed with a self-generated key, which is why Play Protect does not recognise it.
